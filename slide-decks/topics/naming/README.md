# Meaningful Naming

## Reading Assignment

**Required for presenters:** Read Chapter 2, "Meaningful Names," from [*Clean Code*](https://openlibrary.org/books/OL26222911M/Clean_Code) (pages 17-30) before leading this session.

**Suggested for attendees:** Reading the chapter beforehand is encouraged but optional. It is conversational, full of immediate examples, and provides useful context for the discussion.

The chapter establishes the central idea for this session: we are authors writing code for human readers, and we spend more than 10 times as much time reading code as writing it.
