# Mastering AI Craftsmanship

This deck is a static Reveal.js presentation. Publish the `slide-decks/intro` directory with the repository through GitHub Pages, or run a local static server from the repository root:

```powershell
npx --yes http-server .
```

Keep the terminal running, then open `slide-decks/intro/` from the printed URL. Opening the file directly with `file://` can prevent speaker view from working because the browser assigns it a `null` origin. After editing, use `Ctrl+Shift+R` to hard-reload the deck; restarting the server is not necessary. If an existing speaker window says `localhost refused to connect`, confirm the server is running, close the old window, and press `S` again after the hard reload.

Use the arrow keys or Space to advance. Press `Esc` for overview mode and `S` for speaker view.
