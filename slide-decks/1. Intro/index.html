Bowling Game Kata

Contract and rules

game = new Game()
game.roll(pins)
game.score()
  • Accept rolls and return the final score.
  • There are 10 frames. An open frame has up to 2 rolls.
  • A spare uses both rolls for 10 pins and adds the next roll.
  • A strike uses one roll for 10 pins and adds the next two rolls.
  • The tenth frame can receive bonus rolls after a spare or strike.

Build it test-first

Start: gutter game, all rolls score 0.

Then: one-pin rolls, an all-open game, one spare, and one strike.

Finish: consecutive strikes, a spare or strike in frame 10, and a perfect game.

all gutters       -> 0
all strikes       -> 300
9 / 0 repeated    -> 90
5 / 5, 3          -> spare + 3 bonus

Prime Factors Kata

Contract and rules

PrimeFactors.generate(n)

1  -> []
2  -> [2]
8  -> [2, 2, 2]
12 -> [2, 2, 3]
30 -> [2, 3, 5]
  • Accept a positive integer and return its prime factors.
  • Return factors in ascending order.
  • Repeat factors according to their multiplicity.
  • Do not return 1: it is not prime.

Build it test-first

Start: make 1 produce an empty list.

Then: add 2 and 3, followed by 4, 6, 8, and 9.

Finish: cover repeated and mixed factors such as 12, 18, 24, and 30.

Keep each cycle small: write one failing example, make it pass, then refactor while the tests stay green.
